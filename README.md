## 표기 규칙
- `TODO(팀)` : 팀이 채우거나 결정해야 하는 항목
- `제안` : 초안 단계의 제안값. 팀이 확정하면 `제안` 표기를 지웁니다.
- 결정이 바뀌면 해당 문서를 먼저 고친 뒤 AI에게 작업을 요청합니다. (문서가 항상 코드보다 앞선다)
