# PAGES — 페이지별 명세

공통: 모든 페이지 = `Header(GNB)` + 본문 섹션들 + `NextStepCTA` + `Footer`.
문구는 `src/content/`에서 관리한다. 아래 "카피"는 초안이며 `CONTENT.md`에 원문이 있다.

## 1. 온보딩 `/intro`
**목적**: 2031년 세계관에 30초 안에 몰입시킨다. 발표 첫 장면.

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 장면 1 — 시대 | "2031년. AI가 우리의 일을 대신하게 되었습니다." |
| 2 | 장면 2 — 잃은 것 | "우리는 일자리와 함께, 서로를 잃어가고 있었습니다. 그리고 우리 자신의 '인간적인 감'도." |
| 3 | 장면 3 — 생존키트 | 문 앞에 도착한 생존키트(사진 ⑤ 또는 누끼컷). "당신에게 생존키트가 도착했습니다." |
| 4 | 장면 4 — 초대 | 초대장 이미지 + "연대노동조합이 당신을 초대합니다." + [들어가기] [로그인] |

- 장면 전환: 클릭 / 스페이스 / 스크롤로 다음 장면. 발표자가 리모컨·키보드로 넘길 수 있어야 한다.
- 우측 상단 [건너뛰기] 항상 노출.
- 마지막 장면 이후 다시 보지 않음 (`FEATURES.md` §2).

## 2. 메인 `/`
**목적**: 세계관의 얼굴. 실사 사진 5장으로 각 페이지의 입구를 만든다.

| 순서 | 섹션 | 사진 | 내용 | 링크 |
|---|---|---|---|---|
| 1 | 히어로 | ① 착용 측면 | 로고 + "우리는 일자리를 잃었지만, 서로를 잃지 않는다" + 연대노동조합 · 2031 | 선언문 |
| 2 | 키트 소개 | ② 착용 정면·후면 | "당신에게 도착한 생존키트" 한 줄 설명 | 키트 설명 |
| 3 | AI키우기 입구 | ③ 소품이 빠져나오는 연출 | "우리가 함께 키우는 아이" + 실시간 '모인 마음 수' | AI키우기 |
| 4 | 커뮤니티 입구 | ④ 가방·소품 나열 | "아이를 어떻게 키울까요?" + 최근 토론 1~2개 미리보기 | 커뮤니티 |
| 5 | 가입 입구 | ⑤ 내용물 펼침 | "생존키트를 받고 연대의 일원이 되세요" | 가입하기 |

- 각 섹션은 **사진이 화면의 절반 이상**을 차지하는 큰 구성. 사진 위 텍스트는 대비 확보(`DESIGN.md` §5).
- 섹션 번호 표기 "01 / 05" 같은 인덱스로 순서감을 준다 (이전 버전의 좋은 점 유지).
- 로그인 사용자: 히어로 하단에 "조합원 No.#3903님, 오늘 아이에게 마음을 전했나요?" 한 줄.
- 로그인 사용자의 가입 섹션(5) 링크는 "AI키우기로 가기" (IA.md §3, 이미 가입함).
- `TODO(팀)` 각 섹션의 링크 문구와 섹션 3~5의 설명 문장이 정해지지 않았다. 지금은 링크에 메뉴 이름("선언문 →", "생존키트 →" …)을 쓰고, 섹션 2만 CONTENT.md §3 키트 소개 문장([초안])을 쓴다.

**로딩 화면** (2026-11-17 추가): 메인에 들어올 때마다 로고 심볼이 짧게 등장했다 사라진 뒤 히어로가 보인다. 이전 버전의 프리로더를 이은 것. 동작은 `FEATURES.md` §3.5.

**스크롤 연출** (2026-11-17 추가): 섹션 2~5는 스크롤에 따라 장이 넘어가는 하나의 이야기로 보여준다.
- 데스크톱: 사진이 화면 한쪽(절반 이상)에 고정되고, 스크롤하면 사진이 다음 장으로 바뀌며 반대쪽 텍스트(인덱스 · 제목 · 한 줄 설명 · 링크)가 함께 바뀐다. 진행 표시(점 + "02 — 05" 카운터)는 이전 버전의 좋은 점을 잇는다.
- 이전 버전과 달리 **3D 조끼 회전은 쓰지 않고 실사 사진 ②~⑤로** 한다 (PRD §6). 휠을 가로채지 않고 일반 페이지 스크롤을 쓴다.
- 정지 화면에서도 각 장이 읽혀야 한다 (PRD §3). 동작·예외는 `FEATURES.md` §3.6.

## 3. 선언문 `/manifesto`
**목적**: 조합의 모토와 강령을 전한다. 경로 A의 입구.

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 타이틀 | "우리는 일자리를 잃었지만, 서로를 잃지 않는다" / 2031. 03. 01 창립 선언 / 서명 수 |
| 2 | 문학적 뿌리 | 톨스토이 인용과 출처 |
| 3 | 전문 | "AI가 인간의 노동을 대체한 시대…" 서문 |
| 4 | 강령 제1~4조 | 조 번호 + 제목 + 본문 (`CONTENT.md` §2) |
| 5 | 맺음 | 창립 선언 인용 |

- 서명 수는 실제 가입자 수 + 기본값(세계관 숫자)으로 표시 (`FEATURES.md` §4).
- NextStepCTA → 가입하기.

## 4. 키트 설명 `/kit`
**목적**: 생존키트 5개 구성품과 각각의 의미를 보여준다. 경로 B의 입구.

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 인트로 | 사진 ② + "실직한 노동자에게 배부되는 연대노동조합의 생존키트" + 키트의 역할(사람을 웹사이트와 실제 만남으로 모으는 장치) |
| 2 | 펼쳐보기 | 사진 ③ 또는 ⑤ 위에 번호 핫스팟 ①~⑤ (발표자료 13p 구성처럼) |
| 3 | 구성품 상세 ×5 | 누끼컷 + 이름 + 의미 (`CONTENT.md` §3) |
| 4 | 키트가 하는 일 | 키트(물리적 연대) ↔ 웹사이트(아이 키우기, 온라인 만남)의 역할 분담 |

- 핫스팟 클릭 → 해당 구성품 상세로 스크롤.
- NextStepCTA → 가입하기 ("생존키트 받기").

## 5. 가입하기 `/join`
**목적**: 조합 가입 = 키트 받기 = 계정 생성. 세계관 속 가상 절차이지만 **계정은 실제로 만들어진다.**

| 단계 | 제목 | 입력 |
|---|---|---|
| Step 1 | 당신은 누구인가요 | 이름(불리고 싶은 이름), AI 이전 당신의 일 |
| Step 2 | 연락처 | 이메일(로그인 ID), 비밀번호, 연락처(선택) |
| Step 3 | 왜 연대하나요 | 가까운 마음 다중 선택 + 전하고 싶은 말(선택) |
| Step 4 | 서약 | 서약문 + 동의 체크 |
| 완료 | 연대의 일원이 되었습니다 | 조합원 번호(Member No.) 카드 + "생존키트가 발송되었습니다"(가상) |

- 상단 진행 표시(Step 1/4).
- 이전 단계로 돌아가도 입력값 유지.
- 완료 화면의 조합원 카드는 캡처해서 논문·발표에 쓸 수 있을 만큼 완성도 있게.
- 완료 CTA → AI키우기 "아이에게 첫 마음 전하기".
- `TODO(팀)` 연락처 수집 여부: 테스트 참여자의 실제 전화번호는 개인정보이므로 **선택 입력 또는 제외를 권장**.

## 7. AI키우기 `/grow` ★ 핵심 페이지
**목적**: 모두가 하나의 아이(AI)를 키운다. 사람들은 아이에게 경험과 감정을 들려주며 교감하고, 자신의 '인간적인 감'을 상기한다.

| 영역 | 내용 |
|---|---|
| 아이(중앙) | 화면 중앙에 희미하게 존재하는 유기적 형태. 마음이 전해질 때마다 **색채와 형태가 울렁거리며 변한다** (`FEATURES.md` §3) |
| 헤드카피 | "오늘, 아이에게 무엇을 전할까요" |
| 카운터 | "102,418개의 마음이 모였습니다" (실시간 증가) |
| 입력창 | 감정 선택(8개 칩) + 경험 텍스트(최대 300자) + [전하기] |
| 방금 전해진 마음들 | 다른 사람들의 입력이 실시간으로 흘러 들어오는 피드 (이름·감정·시간) |
| 성장 기록 | 감정별 누적 분포, 참여자 수, 아이가 자란 시간 |

- 비로그인: 아이와 피드는 보이지만 입력창은 "조합원만 아이에게 마음을 전할 수 있어요 → 로그인/가입" 상태.
- 입력 직후: 입력한 글이 아이에게 빨려 들어가는 연출 → 아이 변화 → "전해졌어요. 아이가 당신의 마음을 기억합니다."
- **논문 캡처 기준**: 아이 + 입력창 + 피드가 한 화면(1440×900)에 함께 보이는 구도를 기본 레이아웃으로.
- NextStepCTA → 커뮤니티.

## 8. 커뮤니티 `/community` ★ 핵심 페이지
**목적**: AI가 아닌 **사람들끼리** 이야기하는 광장. 공고판이 아니라 "아이를 키울 때 무엇이 중요한가"를 토론하는 곳.

| 영역 | 내용 |
|---|---|
| 타이틀 | "커뮤니티" + "연대노동조합의 이야기들 — 지금까지 N개의 이야기가 모였습니다" |
| 오늘의 질문 | 상단 고정 토론 주제 1개 (예: "아이에게 '실패'를 어떻게 가르쳐야 할까요?") + 답글 수 |
| 카테고리 필터 | 전체 / 키움 토론 / 오늘의 마음 / 생존키트 / 만남 제안 |
| 버블 광장 | 글 하나 = 버블 하나. **크기 = 대화량(댓글+공감)**, **색 = 카테고리 또는 감정**. 부드럽게 떠다님 |
| 글 상세(오버레이) | 본문 + 공감 + 댓글 스레드. 댓글이 핵심 |
| 이야기 남기기 | 우하단 고정 버튼 → 작성 모달 → 새 버블이 광장에 떠오름 |

- 버블 안에는 카테고리 · 제목 · 날짜, 큰 버블에는 첫 문장 일부까지.
- **논문 캡처 기준**: 버블 안의 글이 정지 화면에서도 읽힐 크기와 대비. 캡처용으로 버블 움직임을 멈추는 상태가 필요(`FEATURES.md` §3.3).
- 예시 글과 댓글은 `CONTENT.md` §4 (팀이 최종 다듬기 필수).
- NextStepCTA → 메인.
