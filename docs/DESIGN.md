# DESIGN — 디자인 시스템

## 0. 방향
- **키워드**: 연대 · 온기 · 2031 디스토피아 속의 작은 빛
- **아이덴티티**: 최종 발표자료의 **블랙 + 민트(#00FFB7)** 를 그대로 잇는다. 발표 슬라이드에서 웹사이트로 넘어갈 때 하나의 프로젝트로 보이게.
- **주인공은 사진**: 연한 민트·화이트 톤의 키트 실물이 어두운 배경 위에서 빛나도록 배경은 어둡고 차분하게.
- **이전 버전과의 차이**: 이전 버전의 세이지 그린 계열(`#46A88C` 등)은 쓰지 않는다. 발표 아이덴티티로 통일.
- `TODO(팀)` 이 방향(다크 베이스)이 확정인지 확인. 논문 인쇄에서 다크 화면이 무겁게 느껴지면 커뮤니티만 라이트 테마를 두는 안도 가능.

## 1. 디자인 토큰
`src/styles/tokens.css`에 CSS 변수로 정의하고 Tailwind 테마에 연결한다. **이 표에 없는 값은 쓰지 않는다.**

### 1.1 컬러 — 기본
| 토큰 | 값 | 용도 |
|---|---|---|
| `--color-bg` | `#050807` | 페이지 배경 |
| `--color-surface` | `#0E1613` | 카드, 입력창, 오버레이 배경 |
| `--color-surface-2` | `#16211C` | 호버, 선택된 칩 배경 |
| `--color-line` | `#24332C` | 구분선, 테두리 |
| `--color-text` | `#F2FBF7` | 본문, 제목 |
| `--color-text-2` | `#A3BAB0` | 보조 텍스트 |
| `--color-text-3` | `#62786E` | 캡션, 비활성 |
| `--color-brand` | `#00FFB7` | 브랜드 민트 — 강조, 주요 버튼, 활성 상태 |
| `--color-brand-strong` | `#00E2A2` | 브랜드 호버/눌림 |
| `--color-brand-deep` | `#006548` | 민트 위 어두운 면, 그라데이션 하단 |

규칙: `--color-brand`는 **강조와 큰 글자에만**. 긴 본문을 민트로 쓰지 않는다 (프로젝터에서 번짐).

### 1.4 타이포그래피
- 폰트: **Pretendard** (한글·영문 공통). 대체: `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- 제목은 굵고 자간 좁게(`-0.03em`), 본문은 `-0.01em`.

| 토큰 | 크기 | 굵기 | 행간 | 용도 |
|---|---|---|---|---|
| `display` | clamp(64px, 9vw, 160px) | 900 | 1.0 | 히어로 타이틀, 온보딩 |
| `h1` | clamp(44px, 5.5vw, 96px) | 800 | 1.1 | 페이지 타이틀 |
| `h2` | clamp(32px, 3.5vw, 56px) | 800 | 1.15 | 섹션 타이틀 |
| `h3` | clamp(22px, 2vw, 28px) | 700 | 1.3 | 카드·조항 제목 |
| `body-lg` | 20px | 500 | 1.6 | 리드 문단 |
| `body` | 17px | 400 | 1.7 | 본문 |
| `caption` | 14px | 400 | 1.5 | 날짜, 보조 정보 |
| `label` | 12px | 600 | 1.4 | 섹션 인덱스, 태그 (대문자, 자간 `0.2em`) |

규칙: 발표 화면에서 읽혀야 하므로 **12px 미만 금지**, 본문 굵기 400 미만 금지.
특수 스타일 `outline`: 발표자료처럼 글자 외곽선(민트 stroke, 내부 투명) — `display`/`h1`에서 강조 단어에만.

### 1.5 간격 (4px 단위)
`--space-1` 4 · `-2` 8 · `-3` 12 · `-4` 16 · `-5` 24 · `-6` 32 · `-7` 48 · `-8` 64 · `-9` 96 · `-10` 128 · `-11` 192 (px)
- 섹션 사이: `-10`(데스크톱) / `-8`(모바일)
- 페이지 좌우 여백: 데스크톱 64px, 모바일 20px. 콘텐츠 최대 폭 1440px.

## 2. 그래픽 모티프 (발표자료에서 가져옴)
과하게 쓰지 않는다. 페이지당 1개 이하.
- **하프톤 세계지도**: 온보딩, 메인 히어로 배경 텍스처 (낮은 불투명도)
- **점선 밑줄(체인 도트)**: 핵심 문장 강조
- **사다리형 화살표 라인**: 섹션 전환, NextStepCTA
- **로고(AI-I Human Labor Union)**: GNB, 조합원 카드, 파비콘

## 4. 레이아웃
- 12컬럼 그리드, gutter 24px, 최대 폭 1440px.
- 브레이크포인트: `sm` 640 · `md` 768 · `lg` 1024 · `xl` 1440 · `2xl` 1920

## 5. 이미지 규칙
- 사진은 같은 색 보정(약간 차갑고 낮은 채도, 민트·화이트 키트가 돋보이게)으로 통일.
- 사진 위 텍스트: 하단 또는 측면에 `--color-bg` → 투명 그라데이션을 깔아 대비 확보.
- 비율: 히어로 16:9, 메인 섹션 4:5 또는 3:2, 누끼컷은 투명 PNG/WebP 정사각.
- 파일: WebP, 긴 변 2400px 이하. 원본은 `assets-src/`에 따로 보관.
